Выжимка проекта «Уютные лапки» (состояние на июль 2026)
Общая концепция
Название: «Уютные лапки»
Жанр: головоломка / match‑3 с механикой объединения предметов и разблокировкой клеток.
Сюжет: котёнок восстанавливает разрушенное кафе. Есть короткие диалоги (локализованы на русский, английский, турецкий - все кнопки и тип тоже надо локализовывать).

Целевая платформа: VK Mini Apps (интеграция через vk-bridge, VK Storage для синхронизации), в перспективе – Яндекс Игры (пока не делаем, но для удобства функции взаимодействия с платформой ВК и синхронизацией вынесли в отдельные файлы).
Адаптив канваса доски с клетками: десктоп и планшеты (9 клеток в ширину × 7 клеток в высоту), телефоны в портрете (7×9 на мобильных). Всё в процентах, без жёстких размеров (ВАЖНО, никаких жестких размеров нигде).

Файловая структура (текущая)
text
/index.html            – основной HTML, подключает css и js
/css/main.css          – стили (тёмное меню, светлая игровая зона)
/css/modal.css         - стили модалок (но стили мэйн на них тоже могут влиять)
images/chara/     - png картинки 200х300 с персонажами (например gg1.png) 
/images/level1/   - пнг картинки 100х100 с предметами
/images/level2/  и тд для разных уровней - каждый уровень в отдельной папке. 
/js/
   localization.js    – данные локализации (ru, en, tr) и функции setLanguage, getText
	resize.js     - адаптация игрового поля под разные экран (хотя в основном размеры адаптируются в css)
   platform.js        – абстракция платформы (VK Bridge, VK Storage, сохранение/загрузка)
   storage.js         – работа с прогрессом (score, level, highestScore, totalCombines)
   audio.js           – звуковой менеджер (Web Audio, простые звуки)
   dialogue.js        – управление сюжетными диалогами (массив ключей)
   scene.js           – менеджер сцен (loading, menu, dialogue, game)
   sceneConfig.js     – настройки сцен (availableTypes, maxSpawnLevel, orders) 

   game.js            – вся игровая логика (поле, предметы, drag‑and‑drop, анимации)
   app.js             – инициализация приложения, связка всех модулей, обработка UI
   itemData.js      – массив с инфой по предметам.
    order.js        - механика заказов

Пример предмета из itemData: 
const ITEM_DATA = [    {        id: 0,        name: 'kartoha',        displayName: { ru: 'Картошка', en: 'Potato', tr: 'Patates' },      levelNames: {        1: { ru: 'Картошка', en: 'Potato', tr: 'Patates' },        2: { ru: 'Две картошки', en: 'Potato', tr: 'Patates' },        3: { ru: 'Корзинка картохи', en: '', tr: '' },      },        initialLevel: 1,        spawnable: true,        spawnLevels: [3],          spawnRules: { types: [0], levelOffset: [1,2] },   specialCombinations: [],  // массив комбинаций, где этот предмет – результат: [[typeA, levelA, typeB, levelB], ...]    },

В игре две главные подсцены, которые есть в каждой сцене и переключаются между собой по кнпоке в парвой панели: подсцена с диалогами и строкой и подсцена игровая с доской\заказами. Подсцены также должно быть можно переключать по триггерам в коде при выполнении условий игроком (например, старт диалога после достижения определенного уровня).
Важно: .dialogue-container (модалка с текстом) не связана с фоном или подсценой диалога, это просто модалка с текстами диалогов, а не вся сцена. 

Ключевые данные и переменные
Игровое поле (board)
board[row][col] – объект:
type, name: строка (название из ItemData - название файла картинки в папке)
typeIndex: число (индекс в imageNames)
level: число (соответствует папке levelN)
locked: boolean (заблокирована ли клетка)
row, col: координаты
Пустая открытая клетка: { locked: false, row, col } (без type).

Предметы
Список доступных типов задаётся в itemData.js (массив ITEM_DATA или imageNames(старое название)).
Уровни соответствуют папкам images/level1/, images/level2/, ... до leve20.
Максимальный уровень каждого типа определяется автоматически при загрузке спрайтов (maxLevels).
Сцены и настройки
sceneConfig.js содержит SCENE_CONFIGS – для каждой сцены (ID) указываются:
availableTypes: массив индексов типов, которые появляются на поле в данной сцене
maxSpawnLevel: максимальный уровень заказов при генерации в данной сцене
orders: заказы и их настройки для каждой сцены
adjustConfigByPlayerLevel – можно корректировать настройки в зависимости от уровня игрока (например, открывать новые типы).

Глобальные специальные комбинации (SPECIAL_COMBINATIONS) – массив вида [типA, уровеньA, типB, уровеньB, результат-тип, результат-уровень]. Проверяются до обычного объединения.
Особые предметы и выпадение
spawnRules – для каждого особого типа (например, индекс 6) задаётся:
types: массив индексов, которые могут выпасть из этого предмета 
type, level, weight: тип предмета, его уровень и процент шанса выпадения
При клике на выделенный предмет, у которого spawnable = true, запускается performSpawn, который использует эти правила.

Механики:
Генерация поля: 9 открытых клеток в центре (3×3), остальные заблокированы. Начальный уровень предметов – 1 (можно изменить в init).
Drag‑and‑drop:
Зажать предмет, перетащить на пустую открытую клетку → перемещение.
На клетку с таким же типом и уровнем → объединение (повышение уровня предмета) или специальная комбинация.
На заблокированную клетку → объединение разрешено только если рядом есть открытая клетка, и типы/уровни совпадают.
При перетаскивании исходная клетка становится пустой.

Клик по предмету:
Первый клик – выделение рамкой (selectedCell).
Второй клик по выделенному предмету с spawnable = true – рождение нового предмета (анимация перемещения, звёздочки).
Выделение может быть перенесено на другую клетку кликом.
Выделение (selectedCell): одна клетка на поле, рисуется рамка (картинка kletkaramka.png).
Подсказка (hintAnimations): два предмета (лучше один заблокированный) показывают анимацию притяжения (два толчка + пауза), если игрок бездействует 10 секунд.

Анимации:
Пульсация предметов (при объединении, рождении, перемещении) – одноразовая.
Конфетти (цветные кружочки) при объединении.
Звёздочки (6 белых звёзд) при рождении нового предмета.
Анимация перемещения предмета (уменьшенный → рост + перемещение).
Анимация подсказки (два предмета тянутся друг к другу).
Анимации аватаров в заказах и диалогах (покачивания).
Анимаци заказов (появление из уменьшения и исчезание с уменьшением).


Состояния игры: пауза при сворачивании, очки, уровень.
Синхронизация с VK: прогресс (score, level, highestScore) сохраняется в VK Storage через Platform. 

Ключевые функции (важные для разработки)
Game.init(rows, cols) – инициализация поля, загрузка спрайтов.
Game.combineItems(r1, c1, r2, c2) – основная логика объединения (проверка совместимости, специальные комбинации, повышение уровня).
Game.handleClick(row, col) – обработка клика (выделение, спавн).
Game.performSpawn(row, col) – рождение нового предмета из клика.
Game.drawBoard() – отрисовка клеток, предметов, паутинки, выделения.
Game.drawAll() – отрисовка всех слоёв (доска, анимации, призрак (предметов перетаскиваемых), пульсации, подсказка).
Game.findHintPair() – поиск пары для подсказки.
Game.animateLoop() – цикл обновления анимаций (пульсации, фаза подсказки, анимации предметов).

Механика заказов: покупатели заказывают предметы определённого типа/уровня. Игрок перетаскивает предмет на заказ, заказ исчезаем с анимацией и начисляет звездочки.
